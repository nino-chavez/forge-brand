## init

Create a new brand kit through interactive discovery, from an existing preset, or by extracting tokens from website source files.

```bash
brand-forge init [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `--from <preset>` | Fork from an existing brand kit JSON file | — |
| `--from-exploration <dir>` | Extract brand tokens from a website-exploration variant directory | — |
| `-o, --output <path>` | Output path for the brand kit JSON | `brand-kit.json` |

**Modes:**

- **Interactive discovery** (no flags): Prompts for brand name, colors, fonts, personality, audience, and theme mode. Assembles a complete brand kit from your answers.
- **Fork from preset** (`--from`): Loads an existing brand kit JSON as the starting point.
- **Extract from exploration** (`--from-exploration`): Reads source files (HTML, CSS, JS, TS, Svelte, Vue, JSX, TSX) from a directory and extracts colors, typography, spacing, layout, and voice hints via regex. Then prompts to confirm extracted values and fill gaps.

**Extraction details:**

When using `--from-exploration`, the tool extracts:
- Hex colors from CSS and inline styles
- Font families from `font-family`, Google Fonts imports, and CSS variables
- Spacing values from padding, margin, and gap declarations
- Layout max-width from container constraints
- Voice hints from headings, CTA labels, and body text

Extracted values are shown in a summary. You confirm or override each value, then provide any missing information (brand name, mission, etc.).

**Output:** A validated brand kit JSON file. If validation fails, the incomplete kit is still written so you can fix it manually.

## generate

AI-assisted creative proposals. Each sub-command proposes options, displays them for review, and asks you to pick one or discard all. Requires an AI provider key (`OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, or `VERCEL_OIDC_TOKEN`).

### generate palette

Propose color palettes based on brand personality and existing colors.

```bash
brand-forge generate palette [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |
| `-n, --count <n>` | Number of palette proposals | `3` |

**Behavior:** Sends brand personality, domain, theme mode, and anchor color to the AI model. Returns palette proposals with contrast ratio reports. Proposals that fail WCAG contrast checks are marked FAIL and excluded from selection. If you select a passing palette, it replaces the color system in the brand kit and writes the updated file.

### generate voice

Synthesize voice and tone rules from brand identity.

```bash
brand-forge generate voice [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |

**Behavior:** Generates voice attributes, anti-patterns, and writing examples based on brand name, personality, audience, and domain. Displays the proposed voice system and asks to apply or discard.

### generate fonts

Propose font pairings based on brand personality.

```bash
brand-forge generate fonts [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |
| `-n, --count <n>` | Number of pairing proposals | `3` |

**Behavior:** Generates display/body/mono font combinations. Each proposal includes a compatibility report. If you select a pairing, it replaces the typography system in the brand kit.

### generate identity

Generate a brand identity (tagline, mission, positioning, audience, personality) from minimal input.

```bash
brand-forge generate identity [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |

**Behavior:** Uses the brand name and domain (plus existing personality traits if present) to generate a complete identity profile. Displays the proposal and asks to apply or discard.

### generate logo

Generate logo concepts using AI image models.

```bash
brand-forge generate logo [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |
| `-n, --count <n>` | Number of logo concepts | `3` |
| `-o, --output <dir>` | Output directory for generated images | `./output/logos` |
| `-m, --model <model>` | OpenRouter image model ID | `google/gemini-2.5-flash-image` |

**Behavior:** Generates logo concept images using the brand identity, personality, and creative context from the kit. Images are saved to the output directory. Logo images are not automatically added to the brand kit — you review them manually and update the `media.logos` section in the preset JSON.

## export

Export a brand kit to various output formats. Runs QA review gates before exporting (unless skipped).

```bash
brand-forge export <format> [options]
```

| Argument | Description |
|----------|-------------|
| `<format>` | Output format (see table below) or `all` for every format |

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |
| `-o, --output <dir>` | Output directory | `./output` |
| `--skip-review` | Skip QA review gates (not recommended) | `false` |

**Formats:**

| Format | Output File | Description |
|--------|------------|-------------|
| `css` | `{id}.css` | CSS custom properties with `--brand-` prefix |
| `tailwind` | `{id}.ts` | Tailwind CSS preset with theme extension |
| `docs` / `markdown` | `{id}.md` | Design system documentation in Markdown |
| `signal-forge` | `{id}.theme.json` | Theme file for signal-forge presentations |
| `signal-forge-voice` | `{id}.voice.json` | Voice rules file for signal-forge |
| `image-gen` | `{id}.style.json` | Style system for the image-gen tool |
| `figma` | `{id}.figma.json` | Figma design tokens (JSON format) |

**Behavior:** Loads the brand kit, validates it against the schema, runs contrast/font-compat/consistency review gates, and then generates the requested format(s). If review fails, export is blocked unless `--skip-review` is used.

## batch

Export all formats and render all media templates in one command. Produces a complete brand asset package.

```bash
brand-forge batch [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |
| `-o, --output <dir>` | Output directory | `./output` |

**Output structure:**

│   ├── {id}.css
│   ├── {id}.tailwind.ts
│   ├── {id}.md

│   └── {id}.figma.json

│   ├── flyer.png             (1080x1080)

│   ├── prescription-label.png (1080x1080)
│   ├── heat-card.png         (1080x1080)
│   └── business-card.png     (1050x600)
└── favicons/

## review

Run QA review gates on a brand kit and print a detailed report.

```bash
brand-forge review [options]
```

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |

**Review gates:**

| Gate | Checks | Severity |
|------|--------|----------|
| **Contrast** | WCAG contrast ratios between text/background color pairs | Error (blocks export) |
| **Font Compatibility** | Optical compatibility of display/body font pairings | Error or Warning |
| **Consistency** | Internal coherence — spacing scale monotonicity, color completeness, etc. | Error or Warning |

**Output:** Prints each gate's pass/fail status with details on every issue found. Exits with code 1 if any gate fails. Exits with code 0 if all gates pass (warnings are allowed).

## site

Scaffold a new web project with brand tokens pre-wired.

```bash
brand-forge site <framework> [options]
```

| Argument | Description |
|----------|-------------|
| `<framework>` | Target framework: `nextjs`, `sveltekit`, or `static` |

| Option | Description | Default |
|--------|-------------|---------|
| `-k, --kit <path>` | Path to brand kit JSON | `brand-kit.json` |
| `-o, --output <dir>` | Output directory | `.` |

**Framework outputs:**

| Framework | Files Generated |
|-----------|----------------|
| `nextjs` | `styles/brand-tokens.css`, `brand-preset.ts`, `styles/globals.css`, `app/layout.tsx`, `app/page.tsx` |
| `sveltekit` | `src/styles/brand-tokens.css`, `src/styles/app.css`, `src/routes/+layout.svelte`, `src/routes/+page.svelte` |
| `static` | `styles.css`, `index.html` |

All scaffolds include CSS custom properties, Google Fonts loading (when fonts are available on Google Fonts), and a landing page stub using the brand's display font and tagline.

## Environment Variables

| Variable | Purpose | Used By |
|----------|---------|---------|
| `OPENROUTER_API_KEY` | OpenRouter API access (primary AI provider) | `generate` commands |
| `ANTHROPIC_API_KEY` | Direct Anthropic API access (fallback) | `generate` commands |
| `VERCEL_OIDC_TOKEN` | Vercel AI Gateway access (requires `ai` package) | `generate` commands |

These are checked in priority order. Only one is required, and only for `generate` commands. All other commands (`export`, `review`, `media`, `batch`, `diff`, `site`, `init`) work without any API key.

## Glossary

| Term | Definition |
|------|------------|
| **Brand kit** | A JSON file containing the complete design system for a brand — colors, typography, spacing, voice, and media configuration |
| **Preset** | A saved brand kit in the `presets/` directory that has passed validation and review |
| **Review gate** | A quality check that runs before export to ensure the brand kit meets accessibility and consistency standards |
| **Template** | A media template that renders brand-specific images (social cards, flyers, favicons, etc.) |
| **Exploration** | A website prototype directory from the upstream website-exploration tool, used as source material for token extraction |
