## Code Style

### TypeScript

- ESM-only — all imports use `.js` extension
- All colors use `#rrggbb` format (6-digit hex with `#` prefix)
- Strict TypeScript with `noEmit` for type checking

### Formatting

```bash
# Type-check the project
npm run lint
```

No dedicated formatter is configured. Follow the existing code style: 2-space indentation, single quotes, trailing semicolons.

## Module Rules

Follow these rules strictly when modifying code in each module:

| Module | Rule |
|--------|------|
| **Exporters** (`src/core/exporters/`) | Pure functions only. No AI, no network, no randomness. Same input must produce identical output. |
| **Generators** (`src/core/generators/`) | Output must conform to the `BrandKit` schema. AI calls go through `callModel()` in `provider.ts`. |
| **Extractors** (`src/core/extractors/`) | Pure functions only. Regex-based parsing. No AI, no prompts. |
| **Review Gates** (`src/core/review/`) | Return structured reports with `passed`, `issues[]`, and severity levels. |
| **Schema** (`src/core/schema/`) | Changes cascade everywhere. Update all presets and tests after modifying. |
| **Media Templates** (`src/media/templates/`) | Pure JSX functions. Receive `BrandKit` + template data, return React elements. |

## Git Workflow

### Commit Messages

Use descriptive, conventional-ish style:

```
Add palette generator with contrast validation
Fix font compatibility check for condensed + serif pairs
Update signal-dispatch preset with new voice system
```

### Pre-Commit Checklist

Run these before every commit:

1. **Type check passes:**
   ```bash
   npm run lint
   ```

2. **Tests pass:**
   ```bash
   npm test
   ```

3. **If schema changed:** Verify all presets still parse:
   ```bash
   npm run dev -- review --kit presets/630volleyball.json
   npm run dev -- review --kit presets/flickday.json
   npm run dev -- review --kit presets/signal-dispatch.json
   npm run dev -- review --kit presets/volley-rx.json
   npm run dev -- review --kit presets/letspepper.json
   ```

4. **If exporter changed:** Verify output is deterministic — run the export twice and diff.

5. **If generator changed:** Verify output conforms to `BrandKit` schema.

6. **If extractor changed:** Verify extraction is pure (no AI, no prompts).

## Adding a New Exporter

1. Create `src/core/exporters/<name>.ts` with a single export function:
   ```typescript
   import type { BrandKit } from '../schema/brand-kit.js';

   export function exportMyFormat(kit: BrandKit): string {
     // Pure, deterministic transform
     return '...';
   }
   ```

2. Add to `src/core/exporters/index.ts` barrel export.

3. Register in the `EXPORTERS` map in `src/cli/commands/export.ts`.

4. Add to the `exports` array in `src/cli/commands/batch.ts`.

5. Add a test in `tests/exporters.test.ts`.

## Adding a New Generator

   ```typescript
   export interface MyGeneratorOptions { /* ... */ }
   export interface MyProposal { /* ... */ }

   export async function generateMyThing(options: MyGeneratorOptions): Promise<MyProposal[]> {
     const prompt = buildPrompt(options);
     const raw = await callModel(prompt);

   }
   ```

2. Add to `src/core/generators/index.ts` barrel export.

3. Add a sub-command in `src/cli/commands/generate.ts` with interactive approval via `@inquirer/prompts`.

4. The approval step is mandatory — generators propose, humans approve.

## Adding a New Media Template

1. Create `src/media/templates/<name>.tsx` (or `.ts` with JSX):
   ```typescript
   import type { BrandKit } from '../../core/schema/brand-kit.js';

   interface MyTemplateProps { /* template-specific data */ }

   export function MyTemplate(kit: BrandKit, props: MyTemplateProps) {
     // Return React JSX element for Satori
     // Note: Satori supports limited CSS — no Grid, limited flexbox
   }
   ```

2. Register in `src/media/templates/index.ts` with `defaultWidth` and `defaultHeight`.

3. Add sample data in the `templateData` map in `src/cli/commands/batch.ts`.

## Dependency Direction

```
website-exploration → produces winning variant
    ↓
brand-forge (this project) → extracts + produces brand-kit.json
    ↓
signal-forge → consumes as PresentationTheme + VoiceRules
image-gen    → consumes as style system + prompt context
```

Do not import from signal-forge or image-gen. The dependency arrow goes one way: brand-forge produces, downstream tools consume.
