## Quick Start

Get brand-forge running in under 5 minutes.

```bash
# Clone and enter
git clone <repo-url>
cd brand-forge

# Install dependencies
npm install

# Set up AI provider (pick one)
echo "OPENROUTER_API_KEY=your-key-here" > .env

# Run the CLI in dev mode
npm run dev -- review --kit presets/signal-dispatch.json

# Run tests
npm test
```

**Success:** The review command prints a pass/fail report with contrast, font compatibility, and consistency results. Tests should show all green.

## Key Concepts

### The BrandKit Schema

Everything revolves around `src/core/schema/brand-kit.ts`. This Zod schema defines:

- **Identity** — name, tagline, mission, audience, personality
- **Colors** — primary, secondary, accent, neutral scale, semantic, surfaces
- **Typography** — display/body/mono font stacks, type scale
- **Spacing** — spacing scale, border radius scale
- **Layout** — max width, breakpoints, padding
- **Voice** — attributes, anti-patterns, examples
- **Media** — logo system, templates, assets

Every input path must produce valid `BrandKit` data. Every output path consumes it.

### Module Rules

| Module | AI Allowed? | Network? | Deterministic? |
|--------|-------------|----------|----------------|
| Schema | No | No | Yes |
| Extractors | No | No | Yes |
| Generators | Yes | Yes | No |
| Review Gates | No | No | Yes |
| Exporters | No | No | Yes |
| Media Templates | No | No | Yes |
| Media Renderer | No | Yes (font fetch) | Yes (same fonts = same output) |

### The Pipeline

```
Input → Schema Validation → Review Gates → Export/Render
         ↑                                      |
         └──── Generators (AI propose) ─────────┘
                     ↑
              Human approval (interactive prompt)
```

Generators propose changes. Review gates validate. Humans approve via interactive CLI prompts. Only then does the change lock into the schema.

## Troubleshooting

### "No AI provider configured"

**Symptom:** Error when running `generate` commands.
**Solution:** Set `OPENROUTER_API_KEY` in your `.env` file. This is only needed for generator commands — export, review, media, and batch work without an API key.

### Font rendering issues in media

**Symptom:** All text renders in Inter instead of the brand's fonts.
**Cause:** The font is not available on Google Fonts (e.g., Adobe Typekit fonts).
**Solution:** Provide a local TTF file via the `localPath` field in the font stack, or accept the Inter fallback.

Font cache location: `~/.brand-forge/fonts/`. Delete this directory to force re-download.

### "Brand kit validation failed"

**Symptom:** `ZodError` when loading a preset or generated kit.
**Solution:** Check the error paths. Common issues:
- Missing `#` prefix on hex colors
- Missing required fields (name, schemaVersion, id, created, updated)
- Invalid font classification value

Run `npm run dev -- review --kit <path>` after fixing to verify.

### Tests fail after schema changes

**Symptom:** Tests in `tests/schema.test.ts` or `tests/review.test.ts` fail.
**Cause:** Schema changes cascade to presets and test fixtures.
**Solution:** Update all presets in `presets/` to match the new schema, then re-run tests.

### Port/process issues

brand-forge is a CLI tool with no long-running server. If a command hangs, it is likely waiting for an AI API response. Check your network connection and API key validity.
